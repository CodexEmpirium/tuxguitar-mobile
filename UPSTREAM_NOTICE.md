# Upstream notice

TuxGuitar Mobile is directly derived from the concepts, source layout, and song model of [TuxGuitar](https://github.com/helge17/tuxguitar), whose local checkout is expected at `../tuxguitar` during development.

The upstream project describes itself as an open-source multitrack tablature editor and player written in Java and released under the GNU Lesser General Public License. This iOS project is a separate native Swift implementation; it does not copy the upstream Java sources into the iOS target.

The upstream project remains the authoritative reference for file formats, notation semantics, and feature compatibility. Before distributing a build that includes translated upstream code or upstream assets, retain the applicable upstream copyright and license notices alongside that code.
